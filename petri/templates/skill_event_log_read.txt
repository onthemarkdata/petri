# Event Log Read

Query events from a cell's event log.

## Usage

```python
from pathlib import Path
from petri.query import query_events, get_verdicts
from petri.storage.paths import dish_db_path

db_path = dish_db_path(Path("$petri_dir"), "{dish_id}")

# Read all events for the target cell.
events = query_events(db_path, cell_id="{cell_id}", limit=None)

# Query by filters
results = query_events(db_path, cell_id="{cell_id}", event_type="{type}", iteration={n})

# Get verdicts for a cell + iteration
verdicts = get_verdicts(db_path, cell_id="{cell_id}", iteration={n})
```

## Important

- Events are read from the dish's append-only SQLite events table.
- Use query parameters to filter efficiently.
- Use `petri.query` for read-only access; exported text is a derived view.
