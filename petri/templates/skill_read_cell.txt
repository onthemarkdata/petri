# Read Cell

Read a cell's current state, metadata, and evidence.

## Usage

```python
from pathlib import Path
from petri.query import get_cell
from petri.storage.colonies import load_colony
from petri.storage.paths import dish_db_path

db_path = dish_db_path(Path("$petri_dir"), "{dish_id}")

# Read current metadata and evidence without changing the database.
metadata = get_cell(db_path, "{cell_id}")
if metadata is None:
    raise ValueError("Cell not found")
evidence = metadata["evidence_md"]

# Load full colony graph
graph, colony = load_colony(db_path, "{colony_id}")

# Get specific cell
cell = graph.get_cell("{cell_id}")
```

## Storage

Cells, edges, evidence, and events live in
`.petri/petri-dishes/{dish_id}/petri.sqlite`. Use `petri export` to generate
reviewable text; editing an export does not update the database.
